# Python 零基础补给线（3 天，每天 2 小时）

给完全没写过 Python 的前端。**不做语言教学，只补到能读懂 AI 应用代码为止。**

> **系统教程在 [docs/](docs/README.md)** —— 10 章，从变量一直讲到异步，
> 每章都有「在 AI 应用里，它出现在哪」一节。
> 本文件是 **3 天的时间安排**，教程是**学习材料**。

---

## 先做一件事：读速查表（30 分钟）

打开 [js_to_python.md](js_to_python.md)，从头读一遍。不要背，不要做笔记。
目的只有一个：让你知道"JS 里的这个东西，Python 里长什么样"。

重点看这三节，它们是你最容易踩的坑：
- **第 4 节 字典** —— Python 不能用点号取值，`user.name` 会报错
- **第 5 节 函数** —— 可变默认参数 `def f(items=[])` 是经典 bug
- **第 10 节 包管理** —— 没有 `node_modules` 自动隔离，必须手动建虚拟环境

## 三个脚本分别教什么

| 文件 | 学到的 Python 概念 | 对应的 AI 开发场景 |
|---|---|---|
| `01_hello_llm.py` | import、变量、f-string、字典、`with`、嵌套取值 | 调用一次大模型 API |
| `02_stream_chat.py` | 函数、while 循环、列表、for、`break`/`continue` | 流式输出 + 多轮记忆 |
| `03_chunk_text.py` | 函数默认参数、切片、`join`/`split`、`enumerate`、入口判断 | RAG 的文本切片 |

三个都**零依赖**（只用标准库），不需要 `pip install` 任何东西。
全部已实测跑通。

## 三天安排

### Day 1（2h）· 教程 01–03 章 · 跑通第一次调用

```bash
cd ai-lab/python_basics

# 方式 A：没有 API Key，用本地 mock 服务（推荐先这样）
python3 ../week01/mock_server.py                    # 终端 1
OPENAI_BASE_URL=http://127.0.0.1:8765/v1 OPENAI_API_KEY=test python3 01_hello_llm.py   # 终端 2

# 方式 B：有真实 Key（先 cd ../week01 && cp .env.example .env 填好）
export OPENAI_API_KEY=sk-你的key
python3 01_hello_llm.py
```

- 读 `01_hello_llm.py` 的每一行注释
- 做文件末尾的 3 个改造题
- **验收**：能说清 `json.dumps` 和 `.encode("utf-8")` 分别在做什么

### Day 2（2h）· 教程 04–06 章 · 流式与循环

```bash
python3 02_stream_chat.py        # 记得先设好环境变量
```

- 观察文字是"一个字一个字冒出来"还是"一下子全出来"
- 做文件末尾的 3 个改造题
- **验收**：能回答"为什么对话越长越贵"

### Day 3（2h）· 教程 07–09 章 · 第一次写自己的函数

```bash
python3 03_chunk_text.py         # 这个不需要网络，随时能跑
```

- 做文件末尾的 3 个改造题（第 3 题最重要，那是真实 RAG 的数据结构）
- **验收**：能独立写出一个"输入字符串列表、输出字符数总和"的函数
