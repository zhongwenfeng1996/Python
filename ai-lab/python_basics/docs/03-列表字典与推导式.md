## 1. 列表（list）

```python
empty = []
numbers = [1, 2, 3]
mixed = [1, "two", 3.0, True, None]      # 可以混装不同类型（和 JS 一样）
nested = [[1, 2], [3, 4]]                # 嵌套
```

### 索引与切片（和 JS 的 slice 类似）

```python
items = ["a", "b", "c", "d", "e"]

items[0]        # 'a'        第一个
items[-1]       # 'e'        最后一个（JS 要写 items[items.length-1]）
items[1:3]      # ['b', 'c'] 切片：含头不含尾
items[:2]       # ['a', 'b'] 从头取 2 个
items[2:]       # ['c', 'd', 'e']  从第 3 个取到尾
items[::2]      # ['a', 'c', 'e']  每隔一个取
```

> **负数索引是 Python 的杀手锏**：`items[-1]` 拿最后一个元素，
> 在处理对话历史（取最近 N 轮）时特别常用。

### 常用方法

```python
items = [3, 1, 2]

items.append(4)          # 追加一个  → [3, 1, 2, 4]     ★ 不是 push
items.extend([5, 6])     # 追加多个  → [3, 1, 2, 4, 5, 6]  ★ 相当于 concat
items.insert(0, 0)       # 在位置 0 插入
items.remove(3)          # 删除第一个值为 3 的元素
items.pop()              # 弹出最后一个（并返回它）
items.pop(0)             # 弹出第 0 个
items.sort()             # 原地排序（改自己）
sorted(items)            # 返回新列表（不改自己）
items.reverse()          # 原地反转
len(items)               # 长度
3 in items               # 是否包含
items.index(2)           # 找下标
items.count(2)           # 计数
```

> **前端最常错的一个**：Python 是 `append`，不是 `push`。
> 另外 `sort()` 会**修改原列表**，想要新列表用 `sorted()`。

## 2. 元组（tuple）：不可变的列表

```python
point = (3, 4)
rgb = (255, 0, 0)

point[0]          # 3        可以索引
# point[0] = 5    # ❌ TypeError：元组不可修改
```

**什么时候用元组？**
- 表示"不该被修改的一组值"（坐标、配置、固定选项）
- 函数返回多个值时（下一章讲）

```python
# 解包（unpacking）—— 非常常用
x, y = (3, 4)
print(x, y)        # 3 4

# 交换变量，不需要临时变量
a, b = 1, 2
a, b = b, a
print(a, b)        # 2 1
```

## 3. 字典（dict）：这章的绝对重点

```python
user = {
    "name": "Alice",
    "age": 25,
    "is_active": True,
}
```

对比 JS：

```javascript
const user = { name: "Alice", age: 25, isActive: true };   // key 不加引号
```

> **前端第一坑**：Python 的字典 key **必须加引号**，而且**不能用点号取值**。

```python
print(user["name"])        # ✅ Alice
# print(user.name)         # ❌ AttributeError: 'dict' object has no attribute 'name'
```

### 安全取值：get

```python
print(user.get("email"))            # None（不会报错）
print(user.get("email", "未填"))    # 未填（给默认值）

# 直接取值时 key 不存在会抛异常
# print(user["email"])              # ❌ KeyError: 'email'
```

> **这个区别在生产代码里极其重要**：
> API 返回的字段可能缺失，一律用 `get()` 而不是 `[]`。

### 遍历字典（放到第 05 章讲）

本节没有遍历字典的例子，**因为遍历要用 `for` 循环，而循环在第 05 章**。
第 05 章有专门的「遍历字典」小节，还顺带讲了最常用的「字典计数」写法。

> 与其在这里提前用 `for`（你只能照抄，不知道它在做什么），
> 不如等学会循环之后，把它当成"循环的第一个实用场景"来讲。

### 增删改

```python
user["age"] = 26                    # 改
user["email"] = "a@b.com"           # 增
del user["email"]                   # 删
user.pop("email", None)             # 删（不存在也不报错）

"name" in user                      # 判断 key 是否存在 → True
```

## 4. 嵌套结构：大模型的真实数据形态

**这是本节的核心**。看一个真实的 API 响应：

```python
response = {
    "id": "chatcmpl-123",
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "大语言模型是一种基于海量文本训练的神经网络。"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 14,
        "completion_tokens": 38,
        "total_tokens": 52
    }
}
```

**你要能一眼读出这一行在做什么**：

```python
answer = response["choices"][0]["message"]["content"]
```

> **`response` 是哪来的？** 它是"调用模型 API 之后拿回来的那个字典"
> —— 完整的三步（发请求 → 拿响应 → `json.loads` 转成字典）在
> [第 01 章](01-变量与类型.md#在-ai-应用里它出现在哪)讲过。这里不重复，
> 但请确认你已经知道：`response` 不是凭空出现的变量，而是 `json.loads(raw)` 的结果。
> 想亲眼看真实响应就跑 `python3 week01/show_response.py`。

拆解：
```
response                    dict
  ["choices"]               → list
    [0]                     → dict（取第一个候选）
      ["message"]           → dict
        ["content"]         → str  ← 最终答案
```

**注意"有的是 dict，有的是 list"**——这是新手最容易搞混的地方。
判断方法：方括号 `[]` 里是**数字**就是列表，是**字符串**就是字典。

```python
response["choices"]              # 字符串 "choices" → 字典取值
response["choices"][0]           # 数字 0        → 列表取值
```

### 安全地读嵌套结构

生产代码里不能假设结构一定正确：

```python
# 脆弱写法：任何一层缺失都会崩
content = response["choices"][0]["message"]["content"]

# 稳健写法
choices = response.get("choices") or []
if not choices:
    raise ValueError(f"响应格式异常：{response}")

content = choices[0].get("message", {}).get("content", "")
if not content:
    print("模型返回了空内容")
```

> `{}` 是空字典，`{}.get("message", {})` 保证下一层 `.get()` 不会崩。
> 这个写法你在 [`week01/chat.py`](../../week01/chat.py) 里能看到。

## 5. 集合（set）：去重的工具

```python
tags = {"python", "ai", "python"}      # 自动去重
print(tags)                             # {'python', 'ai'}（顺序不保证）

numbers = [1, 2, 2, 3, 3, 3]
unique = list(set(numbers))             # 去重
print(unique)                           # [1, 2, 3]

# 集合运算
a = {1, 2, 3}
b = {3, 4, 5}
print(a & b)      # {3}        交集
print(a | b)      # {1,2,3,4,5} 并集
print(a - b)      # {1, 2}     差集
```

> 集合最常用于"去重后计数"，比如统计"最近 30 天有多少个不同的用户登录过"。

## 6. 推导式（Python 最爱的写法）

```python
numbers = [1, 2, 3, 4, 5]

# 列表推导式：[表达式 for 元素 in 可迭代对象 if 条件]
doubled = [n * 2 for n in numbers]              # [2, 4, 6, 8, 10]
evens = [n for n in numbers if n % 2 == 0]      # [2, 4]

# 对比 JS
# const doubled = numbers.map(n => n * 2);
# const evens = numbers.filter(n => n % 2 === 0);
```

**嵌套数据里的推导式**（AI 应用里天天用）：

```python
messages = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！有什么可以帮你？"},
    {"role": "user", "content": "什么是 RAG？"},
]

# 取出所有用户说的话
user_texts = [m["content"] for m in messages if m["role"] == "user"]
# ['你好', '什么是 RAG？']

# 统计总字符数
total_chars = sum(len(m["content"]) for m in messages)
# 21
```

**字典推导式**：

```python
prices = {"starter": 29, "growth": 99}
# 换算成"分"
cents = {k: v * 100 for k, v in prices.items()}
# {'starter': 2900, 'growth': 9900}
```

**其他内置函数**（配合推导式用）：

```python
numbers = [3, 1, 4, 1, 5]
sum(numbers)        # 14
max(numbers)        # 5
min(numbers)        # 1
sorted(numbers)     # [1, 1, 3, 4, 5]
any(n > 4 for n in numbers)    # True   任一满足
all(n > 0 for n in numbers)    # True   全部满足
```

## 常见坑

| 坑 | 说明 |
|---|---|
| `user.name` | 字典不能用点号，要 `user["name"]` |
| `user["not_exist"]` | 会抛 `KeyError`，要用 `user.get("not_exist")` |
| `list.push(x)` | 应该 `list.append(x)` |
| `list.sort()` 以为返回新列表 | 它**原地修改**，要新列表用 `sorted(list)` |
| 分不清 `[]` 里是 dict 还是 list | 数字→列表，字符串→字典 |
| `[1,2] + [3,4]` | 这是拼接得到 `[1,2,3,4]`，不是数值相加 |
| `list * 3` | 会重复三遍：`[1,2]*3` → `[1,2,1,2,1,2]` |
