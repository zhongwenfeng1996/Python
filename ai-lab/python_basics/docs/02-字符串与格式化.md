# 02 · 字符串与格式化

> **一句话总结**：Python 的字符串操作用得比 JS 还多——因为 prompt 就是字符串拼接。

---

## 1. 三种引号

```python
a = '单引号'
b = "双引号"        # 单双引号完全等价
c = """
三个双引号
可以写多行
"""
```

> **前端注意**：JS 里单引号、双引号、反引号有语义区别（只有模板字符串能插值）。
> Python 里单双引号**完全一样**，多行用三引号。

多行字符串常用于写长 prompt：

```python
SYSTEM_PROMPT = """
你是一个数据分析助手。
回答要求：
1. 先给结论，再给依据
2. 涉及数字时必须说明口径
3. 不确定时明确说"不确定"
"""
```

## 2. f-string：Python 的模板字符串

```python
name = "小明"
age = 25

# 基础用法：f 开头，{} 里放变量
print(f"{name} 今年 {age} 岁")        # 小明 今年 25 岁
```

对比 JS：

```javascript
console.log(`${name} 今年 ${age} 岁`);   // JS 用 ${}
```

> **高频错误**：写成 `${name}` 会输出字面的 `${name}`。
> Python 用的是 `{name}`，没有美元符号。

### f-string 的进阶用法（很实用）

```python
price = 1234.5678
print(f"{price:.2f}")          # 1234.57    保留 2 位小数
print(f"{price:,.2f}")         # 1,234.57   千分位分隔
print(f"{0.856:.1%}")          # 85.6%      百分比
print(f"{42:>10}")             #         42 右对齐宽度 10
print(f"{42:<10}|")            # 42        | 左对齐

# 调试神器：变量名也会打印出来（Python 3.8+）
tokens = 1234
print(f"{tokens=}")            # tokens=1234
```

最后一个 `f"{x=}"` 在调 prompt 时极其好用：

```python
temperature = 0.7
max_tokens = 2048
print(f"{temperature=}, {max_tokens=}")
# temperature=0.7, max_tokens=2048
```

## 3. 常用字符串方法

```python
s = "  Hello, World  "

s.strip()               # "Hello, World"    去两端空白（JS 的 trim）
s.lower()               # 全小写
s.upper()               # 全大写
s.replace("l", "L")     # 替换（默认全部替换，不需要正则 /g）
s.split(",")            # 按分隔符切成列表
s.startswith("  He")    # 是否以...开头
s.endswith("  ")        # 是否以...结尾
len(s)                  # 长度（注意是函数，不是属性！）
"World" in s            # 是否包含（JS 的 includes）
```

> **前端注意 1**：JS 是 `s.length`，Python 是 `len(s)`。
> 因为"长度"在 Python 里是通用操作，能作用于字符串、列表、字典。
>
> **前端注意 2**：JS 的 `s.replace("a","b")` 只替换第一个，要全替换得用正则 `/a/g`。
> Python 的 `str.replace()` **默认全替换**。

## 4. join：方向和 JS 相反

```python
parts = ["第一句", "第二句", "第三句"]

result = "。".join(parts)
print(result)      # 第一句。第二句。第三句
```

对比 JS：

```javascript
const result = parts.join("。");     // JS：数组在前，分隔符在后
```

```python
result = "。".join(parts)            # Python：分隔符在前，数组在后
```

> **这个顺序特别容易记错**。记忆方法：**"用什么东西"去 join "哪些东西"**。

一个实用例子——把模型返回的流式片段拼起来：

```python
pieces = ["大", "语言", "模型"]
full_text = "".join(pieces)      # 用空字符串连接
print(full_text)                 # 大语言模型
```

## 5. 原始字符串（写正则和 prompt 时会用到）

```python
path = "C:\new\test"        # ❌ \n 被当成换行符
path = r"C:\new\test"       # ✅ r 开头表示"不转义"
```

## 在 AI 应用里，它出现在哪

**这是 prompt 工程最基础的技能**：

```python
# 1. 拼 prompt 模板
template = f"""
请根据以下资料回答问题。

资料：
{context}

问题：{question}

要求：
- 只根据资料回答，不要编造
- 如果资料中没有答案，回答"资料中未提及"
"""

# 2. 格式化输出（成本报表）
cost = 0.0034
print(f"本次调用成本：${cost:.4f}")      # 本次调用成本：$0.0034

# 3. 多行 system prompt（三引号）
SYSTEM = """你是一个严谨的数据分析助手。
当用户询问指标时，必须先说明采用的是哪个口径。"""

# 4. 拼接流式输出的片段
pieces = []
for chunk in stream:
    pieces.append(chunk)
answer = "".join(pieces)          # 注意顺序：空字符串在前

# 5. 清理模型返回的内容（模型经常带多余空白和 markdown 标记）
raw = "  ```json\n{\"name\": \"test\"}\n```  "
cleaned = raw.strip().removeprefix("```json").removesuffix("```").strip()
```

## 常见坑

| 坑 | 说明 |
|---|---|
| `f"${name}"` | Python 是 `{name}`，没有 `$` |
| `s.length` | 应该写 `len(s)` |
| `parts.join("。")` | 顺序反了，应该 `"。".join(parts)` |
| `s.replace("a","b")` 以为只替换第一个 | Python 默认全替换 |
| 字符串拼接数字 | `"年龄" + 25` 报错，要 `str(25)` 或用 f-string |

## 练习

**1.** 用 f-string 打印一行：`模型 deepseek-chat，温度 0.7，最大 2048 tokens`，
其中温度保留 1 位小数。

**2.** 把 `"  Hello   World  "` 变成一个干净的字符串（去掉多余空格，中间的空格保留一个），
提示：先用 `split()` 再 `join()`。

**3.** 下面的代码想输出 `用-连字符-连接`，但写错了，找出问题：

```python
words = ["用", "连字符", "连接"]
print(words.join("-"))
```

<details>
<summary>参考答案</summary>

**1.**

```python
model = "deepseek-chat"
temperature = 0.7
max_tokens = 2048
print(f"模型 {model}，温度 {temperature:.1f}，最大 {max_tokens} tokens")
```

**2.**

```python
s = "  Hello   World  "
clean = " ".join(s.split())
print(clean)        # Hello World
```

原理：`s.split()` 不带参数时按**任意长度空白**分割，并自动丢弃空串，
得到 `['Hello', 'World']`，再用单个空格连起来。

> 这个"清洗文本"的操作在 RAG 预处理里天天用。
> 对应实现就在 [`03_chunk_text.py`](../03_chunk_text.py) 的 `clean_text()` 函数里。

**3.** `join` 是**字符串的方法**，不是列表的方法。

```python
print("-".join(words))     # 用-连字符-连接
```

记忆：字符串是主动方——"我用 `-` 把这些词连起来"。

</details>
