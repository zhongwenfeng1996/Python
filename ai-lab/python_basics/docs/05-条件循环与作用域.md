# 05 · 条件、循环与作用域

> **一句话总结**：语法比 JS 更简单，但**作用域规则不同**——Python 没有块级作用域，
> 循环变量会泄漏到外面。

---

## 1. 条件判断

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:        # 不是 else if
    print("及格")
else:
    print("不及格")
```

对比 JS：

```javascript
if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

三个差异：

| | JS | Python |
|---|---|---|
| 条件括号 | `if (x > 1)` | `if x > 1:` |
| 代码块 | `{ }` | **缩进**（4 个空格） |
| 逻辑运算 | `&&` `\|\|` `!` | `and` `or` `not` |

```python
# 逻辑运算
if score >= 60 and not is_absent:
    print("通过")

if is_admin or is_owner:
    print("有权限")

# 三元表达式（顺序和 JS 相反！）
status = "成年" if age >= 18 else "未成年"
# JS: const status = age >= 18 ? "成年" : "未成年";
```

> **缩进就是语法**。JS 缩进错了只是难看，Python 缩进错了直接报
> `IndentationError`。编辑器里请打开"显示空白字符"。

## 2. `in` 运算符：比 JS 好用

```python
# 判断成员
if "login" in event_types:
    print("包含 login")

if "key" in my_dict:            # 判断字典的 key
    print("有这个 key")

if "错误" in text:               # 子串判断（JS 是 includes）
    print("文本包含'错误'")
```

## 3. 循环

### for 循环：直接遍历元素

```python
# JS: for (const item of items)
for item in items:
    print(item)

# 遍历字符串
for ch in "abc":
    print(ch)

# 遍历字典
for key in my_dict:
    print(key)
```

### range：生成数字序列

```python
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 5):       # 1, 2, 3, 4（含头不含尾）
    print(i)

for i in range(0, 10, 2):   # 0, 2, 4, 6, 8
    print(i)

# 倒序
for i in range(5, 0, -1):   # 5, 4, 3, 2, 1
    print(i)
```

> `range(5)` **不包含 5**。这个"含头不含尾"的规则和切片一致，
> 是整个 Python 的统一约定。

### enumerate：同时拿下标和元素

```python
names = ["Alice", "Bob", "Carol"]

for i, name in enumerate(names):
    print(f"{i}: {name}")
# 0: Alice
# 1: Bob
# 2: Carol

# 想从 1 开始编号
for i, name in enumerate(names, start=1):
    print(f"第{i}名：{name}")
```

对比 JS：`names.entries()` 或 `forEach((name, i) => ...)`。

### zip：并行遍历多个列表

```python
names = ["Alice", "Bob"]
ages = [25, 30]

for name, age in zip(names, ages):
    print(f"{name} 今年 {age} 岁")
```

### while 循环

```python
count = 0
while count < 3:
    print(count)
    count += 1          # Python 没有 count++ ！
```

> **前端注意**：Python **没有 `++` 和 `--`**，要写 `count += 1`。

### break 和 continue

```python
for i in range(10):
    if i == 3:
        continue        # 跳过本次，继续下一次
    if i == 6:
        break           # 跳出整个循环
    print(i)            # 输出 0 1 2 4 5
```

### for-else（Python 独有，很好用）

```python
for item in items:
    if item == target:
        print("找到了")
        break
else:
    print("循环正常结束（没 break）→ 没找到")
```

`else` 在循环**没有被 break 打断**时执行。这在"查找失败要处理"的场景里很优雅。

### 遍历字典（第 03 章欠下的一笔，在这里还）

第 03 章讲了字典怎么建、怎么取值，但**遍历**得用循环，所以放到这里：

```python
user = {"name": "Alice", "age": 25}

for key in user:                    # 只遍历 key
    print(key)

for value in user.values():         # 只遍历值
    print(value)

for key, value in user.items():     # 同时拿 key 和 value  ★ 最常用
    print(f"{key} = {value}")
```

对比 JS：`Object.entries(user)` 得到 `[[key, value], ...]`，概念一样。

**字典计数**是最常用的组合技（循环 + 字典），值得单独记住：

```python
text = "大模型 应用 开发 大模型 工程 应用"
words = text.split()

# 写法 A：显式判断
counts = {}
for word in words:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

# 写法 B：用 get 的默认值（更简洁，推荐）
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

print(counts)
# {'大模型': 2, '应用': 2, '开发': 1, '工程': 1}
```

> 这个"字典计数"模式在**数据分析和评估脚本**里出现频率极高 ——
> 统计各类错误出现次数、统计各模型调用量、统计 token 分布，都是它。
>
> 注意写法 B 里的 `counts.get(word, 0)`：第 03 章讲过 `get()` 取不到时返回
> 你给的默认值，这里正好用来做"第一次见到就记 0，然后加 1"。

## 4. 作用域（本节最容易踩坑）

### Python 没有块级作用域

```python
# JS
for (let i = 0; i < 3; i++) {}
// console.log(i);   // ❌ ReferenceError: i is not defined

# Python
for i in range(3):
    pass
print(i)              # ✅ 2 —— i 还在！
```

```python
if True:
    x = 10
print(x)              # ✅ 10 —— if 块里定义的变量外面也能用
```

> **这是前端最容易踩的坑**：Python 只有**函数级作用域**，没有块级作用域。
> 循环变量、if 块里的变量都会留在外面。
>
> 实际影响：不要用 `i`、`x`、`temp` 这类短名字，
> 否则后面的代码可能意外用到前面的残留值。

> **"函数内部怎么访问外面的变量"是第 04 章讲的** —— 那需要用 `def`，
> 而函数是第 04 章的内容。这里只讲**不涉及函数**的块级作用域。

## 常见坑

| 坑 | 说明 |
|---|---|
| `if (x > 1)` | Python 不需要括号，写成 `if x > 1:` |
| `x++` | Python 没有自增，用 `x += 1` |
| `&&` `\|\|` `!` | 要写 `and` `or` `not` |
| 缩进不一致 | 混用 tab 和空格会报错，统一用 4 个空格 |
| 循环变量泄漏 | `for i in ...` 之后 `i` 还在，别复用短变量名 |
| `range(5)` 以为到 5 | 实际是 0–4 |
| 三元表达式顺序 | `a if cond else b`，条件在中间 |

**3.** 报 `UnboundLocalError`。

原因：函数内部对 `total` 有**赋值操作**（`total += i`），
Python 会把 `total` 视为局部变量，但它在赋值前被读取了。

两种改法：

```python
# 改法 A：用参数传入、返回值传出（推荐）
def add_up():
    total = 0                 # 在函数内部初始化
    for i in range(1, 6):
        total += i
    return total

print(add_up())               # 15
```

```python
# 改法 B：声明 global（不推荐，但要知道）
total = 0

def add_up():
    global total
    for i in range(1, 6):
        total += i
    return total
```

> **推荐改法 A**。函数不依赖、不修改外部状态，是更可靠的写法——
> 这在后面写可测试的评估脚本时很重要。
