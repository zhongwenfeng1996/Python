## 怎么用这份教程

### 三条规则

1. **必须敲代码**。看懂 ≠ 会写。每章的代码示例至少手敲一遍，不要复制粘贴。
2. **每章末尾的练习必须做**。答案折叠在 `<details>` 里，**先做完再看**，否则等于没做。
3. **卡住超过 20 分钟就跳过**，先往下走。很多概念是后面章节才讲清楚的，回头再看就懂了。

### 不要这样做

- ❌ 一次读完 10 章（会全部忘光）
- ❌ 只看不敲（三天后你还是写不出代码）
- ❌ 去搜"Python 从入门到精通"的通用教程（那些教你写爬虫和九九乘法表，和你的目标无关）

### 「零前置」是这个教程的硬规则

**第 N 章的示例只允许用到第 1..N 章教过的东西**，不许提前用后面的语法。
理由很实际：新手看到没学过的写法不会"跳过继续读"，而是**卡在那里怀疑自己**。

规则用脚本强制执行（在仓库根跑）：

```powershell
& G:\转型\.venv\Scripts\python ai-lab\tools\check_doc_prerequisites.py
```

**尺度**（刻意留了余地，否则会为了形式牺牲内容质量）：

| 必须"先教后用" | 允许"看名字就懂、不必先教" |
|---|---|
| `def`、`class`、`async`/`await`、装饰器、推导式、切片、`isinstance`、`try/except` | `for`、`while`、`if`、`import`、`with` |

后一类只要在该节开头用一句话交代"这是干什么的"即可 —— 它们**不会让人彻底卡死**，
而前一类不懂含义就会写出错代码，或者理解整段逻辑时断链。


## 遇到报错怎么办

先读这一节：[10 调试与报错](10-调试与报错.md)。核心就一条：**从 traceback 最后一行往上读**。

然后，如果是环境问题，跑一次自检：

```bash
cd ..                # 回到 python_basics 目录
python3 check_env.py
```
